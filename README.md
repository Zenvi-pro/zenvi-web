# zenvi-web

Zenvi outside the desktop app: the TypeScript engine, the React web editor,
the `zenvi` CLI, the MCP servers that let Claude and ChatGPT edit videos, and
the Zenvi Cloud service that ties them to the desktop editor.

The implementation lands through pull requests against `main`.

Zenvi is a fork of OpenShot. This repository ports OpenShot/libopenshot project
semantics and assets, so it is licensed GPL-3.0-or-later, the same as
[zenvi-core](https://github.com/Zenvi-pro/zenvi-core). See `LICENSE`. The emoji
in `packages/engine/assets/emojis` are [OpenMoji](https://openmoji.org) graphics,
licensed CC BY-SA 4.0, as Zenvi desktop ships them.
