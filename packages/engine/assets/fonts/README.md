# Bundled fonts

Typefaces the engine's typesetter (`src/typography`) sets as SVG outlines, so
every Zenvi renderer draws them without the font installed. Every family is
licensed under the SIL Open Font License 1.1; its licence (with copyright and
any Reserved Font Names) is the `OFL.txt` in its folder. The files are
unmodified copies from the Google Fonts repository (`ofl/<family>`).

| Folder | Family | Category | Files | Source |
| --- | --- | --- | --- | --- |
| `inter` | Inter | grotesk (variable: wght 100-900, opsz 14-32) | `Inter[opsz,wght].ttf` | https://github.com/google/fonts/tree/main/ofl/inter |
| `anton` | Anton | condensed display | `Anton-Regular.ttf` | https://github.com/google/fonts/tree/main/ofl/anton |
| `bebas-neue` | Bebas Neue | condensed display, capitals | `BebasNeue-Regular.ttf` | https://github.com/google/fonts/tree/main/ofl/bebasneue |
| `archivo-black` | Archivo Black | heavy display | `ArchivoBlack-Regular.ttf` | https://github.com/google/fonts/tree/main/ofl/archivoblack |
| `instrument-serif` | Instrument Serif | serif + italic | `InstrumentSerif-Regular.ttf`, `InstrumentSerif-Italic.ttf` | https://github.com/google/fonts/tree/main/ofl/instrumentserif |
| `space-mono` | Space Mono | mono | `SpaceMono-Regular.ttf`, `SpaceMono-Bold.ttf` | https://github.com/google/fonts/tree/main/ofl/spacemono |
| `varela-round` | Varela Round | rounded | `VarelaRound-Regular.ttf` | https://github.com/google/fonts/tree/main/ofl/varelaround |
| `caveat-brush` | Caveat Brush | marker hand | `CaveatBrush-Regular.ttf` | https://github.com/google/fonts/tree/main/ofl/caveatbrush |
| `silkscreen` | Silkscreen | pixel | `Silkscreen-Regular.ttf`, `Silkscreen-Bold.ttf` | https://github.com/google/fonts/tree/main/ofl/silkscreen |

Outlines drawn from these fonts in a title or caption are artwork made with
the font, which the OFL allows without restriction; the font files themselves
ship unmodified with their licences.
