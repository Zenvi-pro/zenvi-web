# Multiplicity (tiles, grids, mirrors, kaleidoscope, split screens)

Design: `auto_sound_design_tool` `{"genre": "multiplicity"}`.
Score / master: `"genre": "multiplicity"`.

- One tick or tonal ping per tile fill, pitched up as the grid fills (a
  scale), panned with the tile's column (pan = tile x × 0.5); a unison swell
  and a centred hit when the tiles merge to full frame. 1.5-3.5 cues/s.
- Rhythmic music; tile fills ride the beat.
- Signature: the sound multiplies with the image (1 → 3 → 6 layers, capped
  at 5).
- Avoid: an identical sample per tile, wide stereo on the merge hit.
