# Zenvi styles: the brief compiler and the one index

Every whole video starts here, before the first edit:

1. **Compile the brief.** Read `BRIEF.md` (this folder) now and follow it:
   `inspect_media_bin_tool`, then the brief, the self-critique against the
   style's checklist, the fixes, and `save_brief_tool`. A few minutes here is
   the difference between a reel and a slideshow.
2. **Pick ONE style** from the table below: the row whose "use when" matches
   what the first five seconds must be. Read only that style's file.
3. **Borrow up to four techniques**, each for one named moment, from the
   style's Mix-and-match list or the techniques table (never one the style
   says to avoid). Read only those files.
4. **Build it.** The style file has the tool sequence; the
   `zenvi-motion-director` skill has the rules every genre shares and the
   frame checks; the `zenvi-sound-designer` skill does the sound pass. Both
   read the saved brief (`get_brief_tool`).
5. **Check against the brief** before you say done: `review_edit_tool` and
   the render receipts report beats, techniques and the checklist against it.

MCP clients without the plugin read the same files as resources: this index
is `zenvi://styles`, the brief compiler `zenvi://styles/brief`, each file
`zenvi://styles/<id>`. The `zenvi_brief` prompt runs step 1.

Do not read every file: this table is the whole library in one place. Tools
listed for a technique are what `save_brief_tool` records in its `tools`, so
review can see the technique on the timeline.

## Adding a style or a technique

A file in `styles/` (one per category, `kind: style`) or `techniques/`
(`kind: technique`) with the front matter below, then
`node plugins/zenvi/scripts/gen-styles-index.mjs` regenerates the table and
the MCP copy (CI fails when either is stale):

```yaml
---
id: flash-frames            # = the file name
kind: technique             # style | technique
summary: When to use it first, at most 120 characters
categories: [sports-hype-edit]
tools: [apply_motion_transitions_tool]   # exact Zenvi tool names
pace: fast                  # calm | medium | fast | frantic
mood: [intense]
aspect: ["9:16", "16:9"]    # quoted: YAML reads 9:16 as a number otherwise
pairs_with: []              # technique ids
avoid_with: []
needs: []                   # missing tool ids from GAPS.md, if any
---
```
