# t005 Perspective UI plane and isometric tiles

## What it is

A flat UI capture laid on a tilted plane (about 25° pitch, 15° yaw) with a
slow dolly and drift, dark on dark, so the product reads as an object, not a
screenshot. The opening or feature beat of developer-tool and SaaS reels;
slow is the point (one move per 6-10 s).

## Build it in Zenvi

There is no free 3D plane. Two honest routes, used back to back:

1. The tilted plane in 2D. Clip `rotation` + `shear_x` + uneven scale give a
   parallel (isometric) plane, not a converging one. Isometric is exactly
   that, so it holds up; a true perspective plane does not.
2. The perspective shot from `add_3d_scene_tool` `device_mockup`: the same
   UI on a laptop with a push and depth of field.

Make the UI first (a motion block, or a real screen recording):

```json
add_motion_block_tool {"block": "code_card", "position_seconds": 0, "duration_seconds": 5, "placement": "full_frame", "params": {"palette": "night", "exit": false}}
```

Take `data.file_id` from its receipt, delete that timeline clip, then place
the file again as the plane and as the device screen:

```json
add_clip_to_timeline_tool {"file_id": "<ui file>", "position_seconds": 0, "start_seconds": 0.5, "end_seconds": 4.5, "track": "1"}
set_clip_properties_tool {"timeline_clip_ids": ["<plane>"], "properties": {"rotation": -20, "shear_x": 0.35}}
set_keyframes_tool {"timeline_clip_id": "<plane>", "property": "scale_x", "points": [{"timeline_seconds": 0, "value": 0.62}, {"timeline_seconds": 4, "value": 0.74, "ease": "ease_in_out_sine"}]}
set_keyframes_tool {"timeline_clip_id": "<plane>", "property": "scale_y", "points": [{"timeline_seconds": 0, "value": 0.53}, {"timeline_seconds": 4, "value": 0.63, "ease": "ease_in_out_sine"}]}
set_keyframes_tool {"timeline_clip_id": "<plane>", "property": "location_x", "points": [{"timeline_seconds": 0, "value": -0.02}, {"timeline_seconds": 4, "value": -0.1, "ease": "ease_in_out_sine"}]}
fade_clip_tool {"clip_id": "<plane>", "fade_in_seconds": 0.5}
add_3d_scene_tool {"scene": "device_mockup", "quality": "draft", "position_seconds": 4, "duration_seconds": 4, "params": {"device": "laptop", "file_id": "<ui file>", "move": "push", "dof": true, "open_lid": false, "background": "#0b0d12", "size": 0.9}}
add_vignette_tool {"amount": 0.4, "feather": 0.6}
```

Look at the draft, then `rerender_3d_scene_tool` `{"timeline_clip_id":
"<device>", "quality": "final"}`. `scale_y` about 0.85 of `scale_x` sells the
pitch; `shear_x` 0.3-0.4 with `rotation` -15…-25 the yaw. Shift
`location_x` so the sheared plane is centred: shear pushes it right.

For the isometric tile cascade use `card_stack` (`animation: "drop"`,
`elevation` 60-70) or `icon_cube`; `floating_cards` with one file renders a
small, nearly frontal card (tested) and does not read as a tilted plane.

## Timing & taste rules

- One move per shot: dolly 15-20 % scale over 4-10 s with `ease_in_out_sine`,
  plus a sideways drift of 0.05-0.1 frame. Never a fast push.
- Dark UI (night or graphite palette) on #0b0d12; vignette 0.4.
- Join the plane and the device with a soft move, not a raw cut (the judge's
  first fix): `apply_motion_transition_tool` `blur_dissolve` or
  `zoom_through` 0.4-0.6 s.
- Keep `open_lid: false` on the device (the default lid-opening move read as
  "floaty") and end on a drift still in motion with a low hit, not a freeze.

## Sound for it

Sparse: an airy swish (-18 dB) as the plane fades in, the UI's own typing
(`typing_burst` -20 dB, only while text types), a whoosh (-16 dB) on the
change to the device, a soft `sub_drop` or `tail_bloom` at the end. Pads or
a quiet pulse underneath; the beat arrives only after the setup.

## Common mistakes

- Tilting by `rotation` alone: a rotated rectangle, not a plane.
- Expecting depth of field on the 2D plane: there is none; keep it in the
  device shot.
- The opening lid on the device shot.
- A typing loop that keeps clicking after the text has stopped.
