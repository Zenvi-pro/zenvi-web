# t045 Staccato sub-second shot burst

## What it is

A run of 6-10 shots of 0.2-1 s each (a 4-6 frame signage strobe, a set of
routine shots), entered by a drum fill, a flash frame or a whip pan, and
left on a held shot. It compresses "a lot happens here" into 2-4 s. Brand
films, app launch sizzles, flash-cut edits.

## Build it in Zenvi

Get the beat grid first, then lay one shot per beat (or per half beat).

```json
detect_beats_tool {"file_id": "<bed>"}
add_clip_to_timeline_tool {"file_id": "<establishing>", "position_seconds": 0, "start_seconds": 1.0, "end_seconds": 3.0, "track": "1"}
add_clip_to_timeline_tool {"file_id": "<shot 1>", "position_seconds": 2.0, "start_seconds": 1.2, "end_seconds": 1.5, "track": "1"}
add_clip_to_timeline_tool {"file_id": "<shot 2>", "position_seconds": 2.3, "start_seconds": 1.5, "end_seconds": 1.8, "track": "1"}
add_clip_to_timeline_tool {"file_id": "<hold>", "position_seconds": 5.0, "start_seconds": 2.0, "end_seconds": 4.2, "track": "1"}
set_clip_audio_video_tool {"timeline_clip_ids": ["<all picture clips>"], "audio": "off"}
apply_motion_transition_tool {"preset": "flash_white", "clip1_id": "<establishing>", "clip2_id": "<shot 1>"}
add_sfx_tool {"recipe": "whoosh_rise", "at_seconds": 2.0, "gain_db": -12}
add_sfx_tool {"recipe": "impact_punch", "at_seconds": 2.0, "gain_db": -8}
add_sfx_tool {"recipe": "impact_boom", "at_seconds": 5.0, "gain_db": -7}
master_audio_tool {"preset": "social", "iterate": true}
```

(continue the run to 8-10 shots, each on the next beat). `build_reel_tool`
does the whole run in one call when the bin holds only the burst shots.
The skewed parallelogram window cascade some references use needs a
polygon mask: `skewed-mask-window-cascade`; use straight hard cuts.

## Timing & taste rules

- Shots 6-30 frames; one length per run (all 9 frames, or all 15).
- 6-10 shots per run, 2-4 s total, then a hold of at least 2 s.
- One entry device only: a 3-frame white flash, or a whip, or a drum fill.
- Shots share one direction of motion or one subject type (signs, hands,
  screens), or the run reads as noise.
- At most one burst per 20-30 s.

## Sound for it

The entry gets a riser or whoosh peaking on the first shot plus a punch;
the cuts inside the run stay dry (the drum carries them); the hold gets
one boom. No foley inside the run.

## Common mistakes

- Varying shot lengths inside the run.
- A hit on every cut of the run.
- No hold after: the burst never lands.
- Random shots with no shared subject.
