# t052 Chart draw and layered diagram reveal

## What it is

The data payoff: a line, bar or donut chart builds itself (bars grow, the line draws, labels count up), or a
diagram's layers glow and their labels slide in one per VO phrase, ending on the highlighted value with a hit.

## Build it in Zenvi

1. The chart, full frame: `add_motion_block_tool` `{"block": "chart_build", "placement": "full_frame",
   "position_seconds": <t>, "duration_seconds": 6, "params": {"kind": "line", "title": "CO2 in the ice, ppm",
   "values": ["280","285","300","330","370","420"], "labels": ["1750","1850","1900","1960","2000","2024"],
   "suffix": "", "palette": "night", "accent": "#ff5a36"}}`. Over footage: `placement: "over_video"` in a window
   from `propose_overlay_windows_tool`.
2. Diagram labels on a plate: `add_motion_block_tool` `{"block": "hud_callouts", "params": {"labels": [...],
   "values": [...], "points": [...], "grid": "none"}}`, timed so each label lands on its VO phrase.
3. Sound: `add_sfx_tool` `{"recipe": "riser_tonal", "at_seconds": <draw end>, "duration": 2.5}` (a riser's
   peak lands on the moment) and `{"recipe": "impact_punch", "at_seconds": <draw end>, "gain_db": -10}`;
   `duck_tool` `{"under": "heroes"}` so the bed clears for the hit.

## Timing & taste rules

- Draw 2-3 s, then hold the end state 2+ s with the highlight; never cut away while it is still drawing.
- One chart per idea, 4-7 data points; the highlighted value is the one the VO says.
- Title in sentence case naming the unit.

## Sound for it

Riser through the draw, a hit on the end state; soft clicks on each label in a diagram build.

## Common mistakes

- Charts with 12 bars on a phone.
- Data invented to look good: values come from the user's source.
