# t090 Fixed-length unit loop

## What it is

A metronome made of content: 5.0 s per letter for 17 letters, about 3 s per fruit, with the reveal at the
same offset inside each unit. After the second unit the child knows when the word will come, and the
anticipation is the engagement. The first unit (a hook pose or dedication) may differ.

## Build it in Zenvi

1. One clip per unit, all the same length: `add_clip_to_timeline_tool` with `position_seconds = i * L`
   and `end_seconds - start_seconds = L` (fix stragglers with `trim_clips_tool` / `move_clips_tool`).
2. Mark the grid: `add_marker_tool` `{"position_seconds": <i * L>, "name": "unit <i>"}`.
3. The reveal at the same offset in every unit: `add_kinetic_title_tool` `{"text": "APPLE", "style": "creator",
   "animation": "pop", "position_seconds": <i * L + 1.7>, "duration_seconds": 1.1, ...}` with `add_sfx_tool` `pop`.
4. Art per unit when there is no footage: `generate_image_and_add_to_timeline_tool` one per unit.

## Timing & taste rules

- Unit length constant to the frame: 2.7-3.1 s for toddler vocab, 5 s for an alphabet card.
- Break the loop once or twice in long pieces (a different length or a transition) so it does not drone.
- End with a payoff unit (all items together) and a held lockup (t069).

## Sound for it

The same cue type at the same offset every unit (with varied seeds); music steady.

## Common mistakes

- Units of random length: the anticipation disappears.
